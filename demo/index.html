tagging

Finds personal data in Luxembourgish, French, German and English text and replaces it with placeholders. The Rust rule engine runs in your browser as WebAssembly, so nothing you type leaves this page.

This page runs the rules and the word lists only. They catch emails, phone numbers, IBANs, card numbers, national IDs of Luxembourg and its neighbours, document numbers, dates of birth, addresses, URLs, IP addresses, the fields of a form (Passwort: …, Name: …), and names that a list knows or that a first name, a title or a company form points to. A surname on its own or a small firm that is in no list needs one of the models in the full Python package.

All example data is made up. Code and evaluation on GitHub
